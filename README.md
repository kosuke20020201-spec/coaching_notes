# Session OS

パーソナルジムとボイトレで聞いたことを、あとから見返すためのシンプルなレッスンメモです。

細かく管理するより、読み返したときに「そうやったわ」と思い出せることだけを残す想定です。

## 使い方

`index.html` をブラウザで開くだけで使えます。

GitHub PagesなどのWebサーバー上に置くと、PWAとしてホーム画面に追加できます。オフライン用の `manifest.json` と `sw.js` も含めています。

記録はブラウザの `localStorage` に保存されます。同じブラウザで開けば前回の内容が残ります。

## 主な機能

- ジム、ボイトレ、横断メモの切り替え
- メモ履歴、検索、フィルタ
- 新規フォルダ作成
- フォルダ名の変更
- フォルダの所属項目をジム、ボイトレ、横断、全体から選択
- フォルダ名と同じタグが付いたメモを自動表示
- フォルダを開くと、そのフォルダ内のメモに一緒に付いているタグだけ表示
- フォルダ内タグを選ぶと、フォルダ条件とタグ条件の両方で絞り込み
- フォルダまたはタグ選択中に新規メモを作ると、必要なタグを自動付与
- 新規メモ、保存、削除
- タイトル、日付、本文、タグだけの簡単入力
- スクロール中も新規メモボタンを上部に固定
- PWA対応

固定タグはありません。フォルダ名そのものを条件タグとして使います。
たとえば `胸` フォルダは `胸` タグが付いたメモだけを集め、フォルダ内では `ベンチ` や `プレス` など一緒に付いているタグだけを表示します。
`肩, ダンベル, プレス` のようなメモは `胸` タグを持たないため、`胸` フォルダには入りません。
ジムで作ったフォルダはジムのタブだけ、ボイトレで作ったフォルダはボイトレのタブだけに表示されます。`全体` にしたフォルダだけ、項目をまたいで使えます。

## バックアップ

- **↓（書き出し）**: 今のメモ・フォルダをJSONファイルとしてダウンロード
- **↑（読み込み）**: JSONファイルを選んで復元（今のデータは置き換わります）
- **☁（クラウドから復元）**: 設定済みのGoogleスプレッドシートから最新バックアップを復元
- **⚙（自動バックアップの設定）**: Apps ScriptのウェブアプリURLを設定すると、保存するたびに自動でGoogleスプレッドシートへバックアップされる
- ヘッダーの状態テキスト（「最終同期OK: ...」など）をタップすると、その場で同期を確認できる。失敗時は赤字で「同期エラー」と表示され、前回成功した時刻も見える

⚙ で設定していない間は、これまでと同じ `localStorage` のみの保存です。ブラウザのサイトデータを削除するとメモも消えるため、⚙ での自動バックアップ設定を推奨します。

セットアップ手順は `apps-script/Code.gs` の先頭コメントを参照してください。
